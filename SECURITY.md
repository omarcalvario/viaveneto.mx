# Reporte de vulnerabilidades

Si encuentras una vulnerabilidad de seguridad, no publiques detalles en un issue público.

Utiliza la opción **Report a vulnerability** de la pestaña **Security** de este repositorio para enviar un reporte privado. Si no está habilitada, contacta al propietario del repositorio por un canal privado antes de divulgar la vulnerabilidad.

El proyecto es un sitio estático; no procesa pagos ni almacena datos de cuentas de usuarios.
